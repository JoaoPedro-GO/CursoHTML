Início dos computadores e da internet

(Voltar)

Os computadores surgiram no século XX e evoluíram ao longo de várias gerações.

Na 1ª geração, destacam-se máquinas como o Mark I, o Colossus e o ENIAC. Esses computadores utilizavam válvulas eletrônicas, eram muito grandes, consumiam muita energia e ocupavam salas inteiras. Mesmo assim, representaram um grande avanço para a época, pois conseguiam realizar cálculos de forma automática.

Na 2ª geração, houve uma evolução importante com a substituição das válvulas por componentes menores e mais eficientes, o que tornou os computadores mais rápidos, confiáveis e com menor consumo de energia.

Na 3ª geração, os equipamentos passaram a utilizar tecnologias ainda mais avançadas, permitindo maior capacidade de processamento e redução de tamanho, além de melhorias no desempenho geral.

Na 4ª geração, surgiram os computadores pessoais, com componentes cada vez mais compactos e potentes, tornando a informática acessível ao uso doméstico e profissional.

A internet teve origem em um projeto chamado ARPANET, criado nos Estados Unidos para conectar computadores e permitir a troca de informações à distância. A partir dessa rede, novas tecnologias foram desenvolvidas, dando origem à internet que utilizamos atualmente.

Introdução ao HTML

(Voltar)

O HTML - HyperText Markup Linguage, ou seja, linguagem de demarcação de hipertexto. Essa linguagem é utilizada para criar a estrutura de uma pagina web, basicamente o esqueleto dela.

Um arquivo HTML possui uma estrutura básica que define o início do documento, o corpo da página e os elementos que aparecem na tela. Essa organização garante que o site seja exibido corretamente em diferentes dispositivos.

Tags

(Voltar)

As tags são os principais elementos do HTML. Elas funcionam como marcações que informam ao navegador o tipo de conteúdo que está sendo exibido, como textos, títulos, imagens ou listas.

Algumas das tags mais básicas e utilizadas são:

  • <font>
    Pouco utilizado atualmente.
  • <h1>até <h6> – usadas para títulos, do mais importante ao menos importante. Exemplo: <h1>Meu site</h1>
  • < p > – usada para criar parágrafos. Exemplo: < p > Este é um texto simples. < /p >
  • < br > – quebra de linha dentro do texto. Exemplo: Texto < br > Nova linha
  • < a > – usada para criar links. Exemplo: <a href="link.com">Link Exemplo</a>
  • < ul > e < ol > – usadas para criar listas não ordenadas e ordenadas.

Atributos

(Voltar)

Os atributos são informações extras que podem ser adicionadas às tags do HTML. Eles servem para definir detalhes importantes sobre o comportamento e a função de cada elemento.

Com os atributos, é possível indicar, por exemplo, para onde um link deve levar, qual imagem será exibida ou como um conteúdo deve se comportar na página. Sem eles, muitas funcionalidades básicas não seriam possíveis. Os atributos sempre aparecem dentro da própria tag.

Exemplos:

  • < a href="https://exemplo.com" >
  • < a target="_blank" >

Textos

(Voltar)

As tags de texto são responsáveis por estruturar o conteúdo escrito. Os títulos (h1, h2, h3…) organizam o assunto por níveis de importância. O parágrafo (p) é usado para desenvolver as ideias de forma contínua. O blockquote destaca citações ou trechos que merecem atenção especial.
